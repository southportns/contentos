## 6. structuralNaturalness Implementation

- **Schema**: `ExpressionAuditDimensions.structuralNaturalness: number (0-100)`
- **Weight**: 0.2（与 naturalness 并列最高）
- **Prompt**: 9 项检查清单（每段功能过于明显、每段长度高度一致、每个观点立即解释/总结、转折高度规律、结论过早、情绪曲线过于平滑、观点推进像公式、开头→问题→原因→方法→总结）
- **Issue Type**: `predictable_structure` → Rewrite 策略：打破公式化推进
- **Key Principle**: 区分"清晰结构"和"过度结构化"，不因结构清晰直接扣分

---

## 7. Legacy Humanization New Role

- **Default Path**: 不执行。Expression Engine 已承担真人表达能力
- **Trigger**: `useLegacyHumanization = true`
  - A. 用户主动调用旧功能
  - B. 旧 API / 旧流程兼容
  - C. Expression Engine 不可用时的 fallback
  - D. 明确指定 legacy mode
- **Skill 保留**: 完整保留 humanization skill + API route，不删除
