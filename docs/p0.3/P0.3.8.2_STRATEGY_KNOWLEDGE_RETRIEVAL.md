## 1. 目标

建立 **Content Strategy 的知识检索管道**，将用户输入转化为检索查询，调用语义搜索，并通过 P0.3.8.1 定义的契约转换为 `StrategyKnowledgeContext`。

---

## 2. 架构定位

```
Strategy Query (由调用方构建)
     ↓
retrieveStrategyKnowledgeContext (本模块)
     1. SemanticSearch.search()           (P0.3.2-3 现有单例)
     2. buildKnowledgeContext()           (P0.3.7.3 Builder)
     3. toStrategyKnowledgeContext()      (P0.3.8.1 Adapter)
     ↓
StrategyKnowledgeContext
     ↓
Strategy Skill → Prompt Assembly (P0.3.8.3) → LLM
```

---

## 3. 核心设计决策

### 3.1 优雅降级 (Graceful Degradation)

| 故障类型 | 行为 |
|---------|------|
| Embedding provider 不可用（无 API key） | 返回 `null`，Strategy 继续纯 LLM 生成 |
| Index 未初始化 / 持久化缺失 | 返回 `null`，Strategy 继续 |
| 网络超时 / provider 故障 | 返回 `null`，Strategy 继续 |

**原则**：检索失败绝不阻塞内容生成流程。

### 3.2 Candidate Policy：Option B

- **检索层**：`include_candidates: true`
- **结果**：已验证 (validated) 和候选 (candidate) 知识都到达 StrategyKnowledgeContext
- **状态保留**：原样保留，不做转换
- **未来**：P0.3.8.3 提示词组装时将明确区分二者

### 3.3 空结果 vs 失败语义

| 场景 | 返回值 |
|------|--------|
| 检索成功 + 0 条结果 | `{ primaryKnowledge: [], supportingKnowledge: [] }` |
| 检索失败 | `null` |

## 4. 实现

### 4.1 文件结构

```
src/knowledge/context/
├── strategy-knowledge-retrieval.ts       # 核心检索编排
├── strategy-knowledge-retrieval.test.ts  # 20 个测试用例
├── strategy-knowledge-context.ts         # P0.3.8.1 Adapter (复用)
└── index.ts                              # 导出新函数
```

### 4.2 核心函数

```typescript
export async function retrieveStrategyKnowledgeContext(
  query: string
): Promise<StrategyKnowledgeContext | null>
```

**参数**：
- `query`: 检索查询（由调用方构建，通常为 `topic + angleTitle + angleDescription`）

**返回值**：
- 成功：`StrategyKnowledgeContext`
- 失败：`null`

### 4.3 检索参数

| 参数 | 值 | 来源 |
|-----|-----|------|
| `limit` | `5` | `DEFAULT_TOP_K` (P0.3.7) |
| `include_candidates` | `true` | Option B 决策 |
| `threshold` | `0.35` | SemanticSearch 默认值 |

## 5. 职责边界

### ✅ 本模块负责
1. 通过现有单例执行语义检索
2. 通过 P0.3.7.3 Builder 构建 KnowledgeContext
3. 通过 P0.3.8.1 Adapter 转换为 StrategyKnowledgeContext
4. 优雅降级：任何检索失败返回 `null`

### ❌ 本模块不负责
- 查询构建（由调用方完成）
- 序列化（Skill 通过 P0.3.7.4 序列化器完成）
- 检索算法 / threshold / topK 逻辑（委托给检索服务默认值）
- 排序 / 过滤 / 选择（委托给 P0.3.7.3 Builder）
- 提示词组装（P0.3.8.3）
- Candidate policy 执行（Contract 层只表达，不过滤）

## 7. 使用示例

```typescript
import { retrieveStrategyKnowledgeContext } from '@/knowledge/context';

// 调用方构建查询
const query = `${topic} ${selectedAngle.title} ${selectedAngle.angle}`;

// 检索知识
const knowledgeContext = await retrieveStrategyKnowledgeContext(query);

// 使用知识
if (knowledgeContext) {
  // Prompt Assembly (P0.3.8.3) 将处理 primaryKnowledge / supportingKnowledge
  console.log('检索到知识:', knowledgeContext.primaryKnowledge.length, '条');
} else {
  // 检索失败，Strategy 继续纯 LLM 生成
  console.log('无知识，使用纯 LLM 模式');
}
```
