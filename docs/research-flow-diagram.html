Content OS — 抖音视频研究流程图

用户输入抖音视频链接后的完整数据采集流程 · useDouyinSearch.researchContent()

📐 图例 — 工具类型说明
抖音微服务 — localhost:8800，基于 jiji262/douyin-downloader，Tabbit 浏览器自动获取 Cookie
douyin-ingest CLI — scripts/di-wrapper.py，基于 ltppp/douyin-ingest，下载视频 + FFmpeg 提取音频 + faster-whisper ASR
LLM (Vercel AI SDK) — src/lib/ai/models.ts，支持 DeepSeek / GLM / Qwen 等，generateText()
文件系统 — 临时目录 %TEMP%/di-audio-*，音频提取中间产物
Next.js API Route — 后端接口，Zod 验证输入，调用 Skill / Tool 层
阿里云百炼 API — dashscope.aliyuncs.com，云端 ASR（Fun-ASR / Qwen3-ASR-Flash）
1

前端编排 — 通用入口

所有模式共享的前 3 步，由 useDouyinSearch hook 编排
1 用户输入抖音链接
入口 explorer/research/page.tsx
Hook useDouyinSearch.researchContent(input)
判断 isDouyinVideoUrl(input)
匹配 douyin.com/video/、v.douyin.com、iesdouyin.com
初始化 进度状态机 researchSteps[]
4 步: search → detail → transcript → comments
→
2 搜索视频（获取详情）
API POST /api/research/search
Skill runContentSearch()
路径 抖音 URL → extractAwemeId() 提取 ID
短链接 → resolveDouyinShortUrl() 跟随 301
→ getVideoDetail(awemeId)
工具 douyin-downloader 微服务
GET localhost:8800/api/v1/video/{awemeId}
超时 30s · 返回: 标题/作者/点赞/评论数/封面
输出 SearchedContent[]
含 url, title, author, metrics, cover
→
⏳
搜索完成
并行触发 ↓
detail 步骤标记 done
2

并行分支 — 口播文案 & 评论采集

搜索完成后同时触发，互不阻塞
⇄ 并行执行（Promise.all 语义）
3T 提取口播文案（ASR）
前端 extractTranscript(url, awemeId)
API POST /api/research/douyin-transcript
Service executeTranscript() — 编排层
输入 urlOrId · mode · quality
mode 优先级: 前端 > ASR_MODE 环境变量 > auto
🖥️ Local 模式 WHISPER_DEVICE=cuda|cpu
3T-L1: 构建 AudioInput
audioInput = { url }
不预提取音频，直接传 URL
→
3T-L2: routeASR()
Provider 选择
mode=local → LocalWhisperProvider
→
3T-L3: douyin-ingest CLI
python scripts/di-wrapper.py
URL --transcribe --model {WHISPER_MODEL}
下载视频 → FFmpeg 提取音频 → faster-whisper ASR
超时 300s · 缓存 TTL 1800s
输出: rawText + segments[] + duration + model + confidence
☁️ Cloud 模式 ALIBABA_ASR_API_KEY=sk-...
3T-C1: 预提取音频
extractAudio(url)
douyin-ingest --speech-audio-dir
下载视频 → FFmpeg 提取音频
不执行 ASR（无 --transcribe）
输出: {awemeId}.speech.mp3
→
3T-C2: routeASR()
audioInput.filePath = mp3路径
→ CloudAlibabaProvider
直接使用 filePath
→
3T-C3: 阿里云百炼 API
FormData multipart 上传
POST dashscope.../audio/transcriptions
model=fun-asr · 超时 120s
输出: text + segments[] + language + duration
⚙️ Auto 模式 硬件检测自动选择
3T-A1: 硬件检测
getHardwareProfile()
nvidia-smi 检测 GPU
Level A/B/C → Local
Level D → Cloud
→
3T-A2: 预提取音频
检测到 Cloud Key →
extractAudio(url)
检测到无 Key → 跳过
→
3T-A3: routeASR()
selectProviderForAuto(hw, level)
A/B/C → LocalWhisper
D → CloudAlibaba
后续流程与选中的模式一致（Local 或 Cloud）
⚠ Failover 容错 — 如果主 Provider 失败，自动切换备用 Provider
Cloud 失败 → Local: douyin-ingest 缓存命中，不重复下载
Local 失败 → Cloud: AudioExtractor 缓存命中，不重复下载
3T-LC LLM 纠错（quality ≥ high 时执行）
Skill runTranscriptCorrection()
generateText() via Vercel AI SDK
模型 getModel() → DeepSeek / GLM / Qwen 等
由 LLM_PROVIDER + LLM_MODEL 环境变量控制
输入 rawText + videoDesc + videoAuthor
视频上下文辅助纠错（如专有名词、品牌名）
输出 correctedText + corrections[] + correctionCount
Structured Output: JSON 解析 + Zod 验证
3C 采集评论数据
前端 collectComments(awemeId)
规则 上限 100 条 · 过滤 < 100 赞 · 按点赞排序
每页 20 条，最多翻页 5 次
API POST /api/research/douyin-comments
工具 douyin-downloader 微服务
GET localhost:8800/api/v1/comments/{awemeId}?count=20&cursor=0
超时 30s · 返回: text/nickname/diggCount/createTime
3C-1: 第 1 页
cursor=0, count=20
获取首页评论
→
3C-2: 翻页循环
while hasMore && < 100
最多 5 页
串行请求，避免风控
→
3C-3: 过滤+排序
filter(diggCount ≥ 100)
sort(desc by diggCount)
3C-A 受众分析（LLM）
API POST /api/analysis/audience
Skill runAudienceAnalysis()
generateText() via Vercel AI SDK
输入 评论列表 → contents[]
每条: nickname + text + diggCount
输出 needs[] + painPoints[] + emotions[]
behaviors[] + contentGaps[]
Structured Output: JSON + Zod 验证
前端 从分析结果提取:
· Top 5 热点评论
· 高频关键词 (needs + painPoints + behaviors)
· 情绪分布 (positive/neutral/negative)
3

汇总输出 — 展示 & 持久化

两个并行分支完成后，结果汇总到前端

文案 setTranscripts[awemeId] = VideoTranscript

评论 setCollectedComments[awemeId] = DouyinComment[]
setCommentAnalysis[awemeId] = CommentAnalysisResult

updateStep('comments', 'done')
→
5 加入内容库（用户操作）
触发 用户点击「加入内容库」按钮
前端 addToWorkflow(contents)
附带 transcript + comments + commentAnalysis
API POST /api/content-library
存储 Prisma + PostgreSQL
ContentLibraryItem upsert by URL
含: platform, title, author, metrics, transcript, comments
→
✅
研究完成
视频详情 + 口播文案 + 评论数据
+ 受众分析 → 内容库
