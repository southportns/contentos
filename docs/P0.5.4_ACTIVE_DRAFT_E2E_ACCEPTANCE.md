## Design Decisions

1. **Component-level E2E over API-level** — 通过 mock server action 而非真实 API 调用，
   聚焦组件间交互链路而非单个 API 行为（后者已在 P0.5.1-P0.5.3 中验证）
2. **BroadcastChannel Harness** — 自研轻量级测试 harness 替代原生 BroadcastChannel，
   实现同步、可控的跨 Tab 消息模拟
3. **Helper Factory Pattern** — `createMockDraft()` + `toVersionDrafts()` 减少模板代码，
   提高测试可读性
4. **Inline Data Consistency 检查** — 将数据完整性断言内联在 describe 块中，
   与组件测试共享同一 mock 数据源
