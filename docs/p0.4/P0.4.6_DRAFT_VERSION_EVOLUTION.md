# P0.4.6 — Draft Version Evolution

## 1. Objective

在 P0.4.5 Version Lineage 基础上，为 Draft 增加"版本演化元数据"，让系统不仅知道：

> 这个版本来自哪个版本。

还知道：

> 这个版本为什么产生。

## 2. Current Problem

P0.4.5 可以回答：

```
v5
↳ 由 v2 创建
```

但是仍然无法回答：

```
为什么创建 v5？
```

## 3. Change Metadata Model

新增两个版本演化字段：

| Field        | Type     | Default    | Description                  |
| ------------ | -------- | ---------- | ---------------------------- |
| changeType   | String   | "INITIAL"  | 版本产生原因类型                      |
| changeReason | String?  | null       | 具体原因描述                      |

## 4. Schema

```prisma
model Draft {
  id            String   @id @default(cuid())
  topicId       String
  version       Int      @default(1)
  parentDraftId String?

  changeType    String   @default("INITIAL")
  changeReason  String?

  title         String?
  content       String
  outline       Json?
  status        String   @default("DRAFT")
  wordCount     Int?
  createdAt     DateTime @default(now())
  updatedAt     DateTime @updatedAt

  topic               Topic                @relation(fields: [topicId], references: [id], onDelete: Cascade)
  parentDraft         Draft?               @relation("DraftLineage", fields: [parentDraftId], references: [id], onDelete: SetNull)
  childDrafts         Draft[]              @relation("DraftLineage")
  evaluation          Evaluation?
  humanization        Humanization?
  strategyEvaluation  StrategyEvaluation?

  @@index([topicId])
  @@index([parentDraftId])
  @@unique([topicId, version])
}
```

## 5. Migration

```sql
ALTER TABLE "Draft"
ADD COLUMN "changeType" TEXT NOT NULL DEFAULT 'INITIAL';

ALTER TABLE "Draft"
ADD COLUMN "changeReason" TEXT;
```

现有所有 Draft 自动获得：
- changeType = 'INITIAL'
- changeReason = NULL

## 6. Change Types

| changeType   | Meaning        | Chinese Label |
| ------------ | -------------- | ------------- |
| INITIAL      | 初始版本           | 初始版本          |
| RESTORE      | 基于历史版本恢复       | 恢复版本          |
| MANUAL_EDIT  | 用户手动修改产生       | 手动修改          |
| REGENERATE   | 重新生成产生         | 重新生成          |
| REFINE       | 精修产生           | 精修            |
| HUMANIZATION | 真人化处理产生        | 真人化           |
| OTHER        | 其他原因           | 其他            |

## 7. Change Reason

`changeReason` 用于记录具体原因：

| changeType | changeReason                    |
| ---------- | ------------------------------- |
| INITIAL    | null                            |
| RESTORE    | "基于 v2 恢复创建"                   |
| MANUAL_EDIT | "用户修改开头钩子"                   |
| REFINE     | "优化表达节奏和口语化程度"               |

## 8. Restore Integration

修改 `createRestoredDraft` 方法：

```typescript
return tx.draft.create({
  data: {
    topicId: sourceDraft.topicId,
    version: nextVersion,
    parentDraftId: sourceDraft.id,
    changeType: 'RESTORE',
    changeReason: `基于 v${sourceDraft.version} 恢复创建`,
    title: sourceDraft.title,
    content: sourceDraft.content,
    outline: sourceDraft.outline,
    status: 'DRAFT',
    wordCount: sourceDraft.content.length,
  },
})
```

## 9. Lineage + Evolution

P0.4.5 (Lineage)：

> 从谁来？ → parentDraftId

P0.4.6 (Evolution)：

> 为什么来？ → changeType + changeReason

两者必须同时存在：

```
v5

来源：
由 v2 创建

演化：
恢复版本

原因：
基于 v2 恢复创建
```

## 11. Consistency Rules

| Rule | Constraint                              |
| ---- | --------------------------------------- |
| A    | INITIAL → parentDraftId 通常为 null          |
| B    | RESTORE → parentDraftId 必须非 null           |
| C    | RESTORE → parentDraftId 与 source 同 Topic    |
| D    | 脏数据不阻断页面（UI 容错）                        |
