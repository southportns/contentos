# P0.4.2 — Draft Version Compare

## 1. Objective

P0.4.1 解决了"我有哪些内容版本？"的问题。本阶段解决：

**"两个版本之间到底发生了什么变化？"**

让用户能够：
- 选择两个版本进行对比
- 查看行级 diff（新增/删除/未变化）
- 查看两个版本的评估数据对比
- 只读操作，不修改任何数据

## 2. Scope

### 本阶段包括
- Version Compare Mode — 在版本历史中切换到对比模式
- Version A/B Selector — 两个下拉选择器分别选择对比版本
- Line-based Diff Algorithm — 纯函数 LCS 算法
- Diff Display — 可视化的 diff 展示（+/- 标记）
- Version Metadata Comparison — 两个版本的评估/策略/真人化对比
- Same Version Protection — 禁止选择相同版本对比
- Swap Button — 快速交换 A/B 版本
- Read-only — 全部为只读展示层

### 本阶段不包含
- 版本恢复、编辑、删除
- AI 判断/自动反馈
- 数据库变化
- 字符级 diff
- 版本导出

## 3. Architecture

```
DraftVersionHistory (client)
  ├─ Detail Mode (default)
  │   ├─ Version List (left sidebar)
  │   └─ Selected Version Detail (right panel)
  └─ Compare Mode (new)
      ├─ DraftVersionCompareSelector
      ├─ Version Metadata Cards (A vs B)
      └─ DraftVersionDiff
```
