# P0.4.2 — Draft Version Compare

## 1. Objective

P0.4.1 solved "What content versions do I have?". This phase solves:

**"What actually changed between two versions?"**

Enable users to:
- Select two versions to compare
- View line-level diff (added/removed/unchanged)
- View evaluation data comparison for both versions
- Read-only operations, no data modification

## 2. Scope

### In Scope
- Version Compare Mode — switch to compare mode in version history
- Version A/B Selector — two dropdown selectors for version selection
- Line-based Diff Algorithm — pure LCS function
- Diff Display — visual diff display (+/- markers)
- Version Metadata Comparison — evaluation/strategy/humanization comparison
- Same Version Protection — prevent comparing same version with itself
- Swap Button — quickly swap A/B versions
- Read-only — purely display layer

### Out of Scope
- Version restore, edit, delete
- AI judgment / automatic feedback
- Database changes
- Character-level diff
- Version export

## 3. Out of Scope (Hard Limits)

- **No Prisma schema changes** — no new tables/columns
- **No database changes** — no migrations
- **No Workflow modifications** — Writing/Evaluation/Refine/Humanization/Strategy Approval unchanged
- **No deletion of existing features** — P0.4.1 Detail Mode fully preserved

## 4. Architecture

```
DraftVersionHistory (client)
  ├─ Detail Mode (default) — P0.4.1 fully preserved
  │   ├─ Version List (left sidebar)
  │   └─ Selected Version Detail (right panel)
  │       ├─ Title / Metadata / Content
  │       ├─ Evaluation (overall/emotional/clarity/novelty/readability/platform)
  │       ├─ Strategy Evaluation (overall/grade/platform/consistency)
  │       └─ Humanization (adopted/not adopted)
  └─ Compare Mode (P0.4.2 new)
      ├─ DraftVersionCompareSelector (A/B selection + Swap)
      ├─ Version Metadata Cards (A vs B)
      └─ DraftVersionDiff (LCS line diff)
```

### Component Hooks Safety

```
DraftVersionCompare          ← conditional return (if drafts.length < 2)
    ↓
DraftVersionCompareContent   ← ALL hooks called unconditionally at top level
    ├─ useState (versionA, versionB)
    ├─ useMemo (draftA, draftB, diffLines)
    └─ helper functions (getDefaultCompareVersions, canCompareVersions, swapCompareVersions)
```

## 9. Limitations

1. **Read-only** — Compare is pure frontend display, no persistence
2. **Line-level only** — No character-level diff
3. **No version restore** — Cannot revert from compare view
4. **Max 2 versions** — A/B only (no multi-version merge view)
5. **Same-version protection** — Selecting same A/B shows message, not diff
