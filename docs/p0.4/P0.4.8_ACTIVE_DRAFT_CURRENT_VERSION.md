# P0.4.8 — Active Draft / Current Version

**Status**: COMPLETED
**Date**: 2026-09-22
**Author**: CatPaw AI (southportns/contentos)

## 1. Overview

为 Topic 建立明确的"当前工作版本"关联（`activeDraftId`），使用户能从多个分支中指定一个继续工作。

核心设计原则：
- **查看 ≠ 切换**：用户浏览历史版本不会改变 active draft
- **显式切换**：仅当用户点击"设为当前版本"时修改数据库
- **自动跟随**：Restore 操作自动将新版本设为 active draft
- **向后兼容**：旧 Topic（无 activeDraftId）通过 fallback 到最高版本保持正常工作

## 3. Architecture

### 3.1 Active Draft Resolution (应用层)

```typescript
export function getActiveDraft<T extends { id: string; version: number }>(
  drafts: T[],
  activeDraftId?: string | null,
): T | null {
  if (drafts.length === 0) return null

  // Case A: activeDraftId explicitly set — find matching draft
  if (activeDraftId) {
    const active = drafts.find((d) => d.id === activeDraftId)
    if (active) return active
    // Case C: activeDraftId points to non-existent draft → fallback
  }

  // Case B / fallback: return draft with highest version
  return drafts.reduce((max, d) => (d.version > max.version ? d : max), drafts[0])
}
```

### 3.2 Active Draft Resolution (数据库层)

```typescript
async getActiveDraft(topicId: string): Promise<Draft | null> {
  const topic = await prisma.topic.findUnique({
    where: { id: topicId },
    include: {
      activeDraft: true,
      drafts: { orderBy: { version: 'desc' } },
    },
  })

  if (!topic) return null

  // Case A: activeDraftId is explicitly set and draft exists
  if (topic.activeDraft) return topic.activeDraft

  // Case B / C: fallback to highest version draft (no write-back)
  return topic.drafts.length > 0 ? topic.drafts[0] : null
}
```

## 8. Design Decisions

### 8.1 Why @unique on activeDraftId?

确保一个 Draft 只能作为一个 Topic 的 active draft。虽然当前业务场景不需要双向唯一性，但 Prisma 一对一关联要求外键字段必须有 `@unique` 约束。

### 8.2 Why onDelete: SetNull?

当 active draft 被删除时，将 activeDraftId 设为 NULL 比级联删除 Topic 更安全。这允许 fallback 逻辑继续工作。

### 8.3 Why No Write-Back on Fallback?

旧 Topic（activeDraftId = NULL）在读取时会 fallback 到最高版本，但不写回数据库。避免在每次读取时产生不必要的事务，保持向后兼容。

### 8.4 Why settingActive State?

防止用户在异步操作进行中重复点击"设为当前版本"按钮，导致多次 API 调用。
