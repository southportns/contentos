# P0.4.1 — Project Detail + Draft Version History

## 1. Objective

把 Content OS 从"生成一次内容"推进到"能够查看和管理自己的内容版本资产"。

本阶段建立只读的内容资产查看机制，支持：
- 查看项目基本信息
- 回溯不同版本的草稿内容
- 查看每个版本的评估数据（Evaluation, StrategyEvaluation, Humanization）
- 不破坏现有工作流和数据结构

## 2. Scope

### 本阶段包括

- **Project Detail Page** — 项目详情页 (`/projects/[id]`)
- **Draft Version History** — 草稿版本历史组件
- **Version Selector** — 版本切换器
- **Content Preview** — 内容预览
- **Evaluation Summary** — 评估分数展示
- **Strategy Evaluation Summary** — 策略评估展示
- **Humanization Status** — 真人化状态展示
- **Read-only presentation** — 只读展示层

### 本阶段不包含

- AI Writing Profile
- 自动风格学习
- 用户反馈闭环
- 数据分析
- 新数据库模型
- 在线编辑历史版本
- 删除历史版本
- 恢复历史版本
- AI 自动总结个人写作风格

## 3. Architecture

### Data Model Hierarchy

```
Project
  ↓
Topic
  ↓
Draft[]
  ├─ Evaluation
  ├─ StrategyEvaluation
  └─ Humanization
```

### Query Flow

```
Project Detail Page
      ↓
getProjectDetail()
      ↓
projectRepository.findByIdWithContentHistory()
      ↓
single Prisma query (nested include)
      ↓
Draft.version DESC
      ↓
Version History UI
```

### Key Design Decisions

1. **Single Query**: 使用 Prisma 嵌套 include 一次加载所有关联数据，避免 N+1 查询
2. **Read-only**: 整个详情页只读，不触发任何数据库写入
3. **Version Ordering**: 按 `version DESC` 排序，最新版本在前
4. **Graceful Degradation**: 数据库未配置时显示友好提示

## 7. Limitations

当前版本仍然是 **Read-only Project Detail**，明确限制：

1. **不能在线编辑历史版本** — 只能查看，不能修改
2. **不能删除历史版本** — 版本历史只读展示
3. **不能恢复历史版本** — 无法将旧版本设为当前版本
4. **不包含 AI 自动总结个人写作风格** — 需要后续阶段实现
5. **不包含版本对比功能** — 无法并排比较两个版本的差异
6. **不包含版本导出功能** — 无法单独导出某个版本
