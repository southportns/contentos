# P0.4.9 + P0.4.9.1 — Active Draft Cross-Tab Sync

## 目标

实现同一浏览器内、同一用户、同一 Topic 的多个标签页之间，实时同步 Active Draft 状态。

## 背景与问题

当用户在多个浏览器标签页中编辑同一个 Topic 的不同 Draft 版本时，一个标签页更改 Active Draft 到其他版本时，其他标签页不会自动感知此变更，导致：

1. UI 上仍显示旧的 Active Draft
2. 用户继续编辑时可能基于错误的版本操作
3. 数据不一致风险

## 范围

- ✅ 使用 BroadcastChannel API 实现标签页通知
- ✅ 数据库为最终事实来源
- ✅ 仅通知机制，数据通过 router.refresh() 从服务器获取
- ❌ 不修改历史 migration
- ❌ 不新增 Prisma 字段
- ❌ 不使用 SharedWorker / WebSocket / SSE

## 技术选型

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| BroadcastChannel | 原生 API，浏览器内实时，轻量 | 仅限同源标签页 | ✅ |
| SharedWorker | 持久化，可协调 | 实现复杂，调试难 | ❌ |
| WebSocket/SSE | 全浏览器支持 | 服务端依赖，架构重 | ❌ |
| localStorage 事件 | 跨浏览器兼容 | 不同源标签页不支持，延迟 | ❌ |

## 消息结构

```typescript
interface ActiveDraftChangeMessage {
  type: 'ACTIVE_DRAFT_CHANGED'
  topicId: string
  draftId: string
  sourceId: string   // 发送方唯一标识
  timestamp: number  // 发送时间戳
}
```

## 安全与降级

1. SSR 安全：BroadcastChannel 仅在 useEffect 中创建
2. 旧浏览器：typeof BroadcastChannel === 'undefined' 时静默降级
3. 内存泄漏：useEffect 清理函数中 close() channel
4. 错误隔离：BroadcastChannel 错误不影响主流程

## 消息过滤策略

### P0.4.9.1 — 统一过滤器 API

`shouldAcceptActiveDraftMessage` 接受 `ActiveDraftSyncFilterOptions` 对象，返回 `boolean`：

```typescript
interface ActiveDraftSyncFilterOptions {
  topicId: string           // 当前 Topic（过滤不同 Topic）
  sourceId: string          // 本机 sourceId（过滤自身消息）
  lastEventTimestamp: number // 最后处理时间戳（过滤过期消息）
  currentDraftId: string | null | undefined // 当前 draft（过滤无效变更）
}
```

过滤逻辑：
1. 类型守卫 (`isValidActiveDraftMessage`) — 拒绝非结构化 payload
2. Topic 不匹配 → 拒绝
3. sourceId 匹配自身 → 拒绝（self-message）
4. 时间戳 <= 上次处理时间 → 拒绝（stale）
5. draftId 与当前一致 → 拒绝（no-change）
6. 全部通过 → 返回 true

## P0.4.9.1 强化总结

| 问题 | 原始实现 (P0.4.9) | 强化实现 (P0.4.9.1) |
|------|-------------------|---------------------|
| API 一致性 | 5 个位置参数 + 返回 `{accept, reason}` 对象 | 单一选项对象 + 返回 `boolean` |
| 类型安全 | 无类型守卫窄化 | 类型守卫 `isValidActiveDraftMessage` 窄化 |
| sourceId 稳定性 | 每次 render 可能不一致 | `useState` 初始化，组件生命周期内稳定 |
| self-message 过滤 | 通过但组件不一致 | hook → 组件 → 过滤器三者统一 |
| 远程 Restore 同步 | `selectedVersion` 不更新 | `useEffect` 监听 `drafts` + `localActiveDraftId` |
| Effect 依赖 | 频繁重建 | 仅 `[topicId]`，其他值通过 ref 传递 |
| 未知 payload 保护 | 无 | 类型守卫拒绝 null/undefined/string/function/错误类型字段 |
