## 1. Validation Framework

### 1.1 Validation Dimensions

| 维度 | 检查项 | 方法 |
|------|--------|------|
| **完整性** | 是否覆盖所有源内容 | 检查每条源内容是否至少被 1 个 KU 引用 |
| **准确性** | 原文引用是否准确 | 逐条核验 evidence_text 与源 transcript 一致 |
| **一致性** | Category 分类是否正确 | 检查每个 KU 的 category 是否符合 P0.2.1 定义 |
| **去重性** | KU 之间是否无冗余 | 检查无重复或高度相似的知识模式 |
| **可溯源性** | Evidence chain 是否完整 | 检查每个 KU 都有 content_ids + evidence_text |
| **置信度合理性** | 置信度分级是否匹配证据数量 | 检查 frequency 与 confidence 是否自洽 |

### 1.2 Validation Criteria

- ✅ **通过**：满足该维度所有检查项
- ⚠️ **警告**：部分满足，存在小问题但不影响使用
- ❌ **失败**：严重问题需要修复
