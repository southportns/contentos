## 5. P_RB Mid-Transaction Rollback Details

**Mechanism**: SQLite `BEFORE INSERT` trigger on `UserContentArchive` table
fires `RAISE(ABORT)` after all entity writes in the save transaction.

**Verification**:
1. Initial save (v1+v2) succeeds → baseline established
2. Trigger installed → subsequent save must fail at archive step
3. Transaction commits? NO — ALL writes rolled back
4. Post-rollback verification:
   - No new topics: Before 0, After 0
   - No new angles: Before 1, After 1
   - No new drafts: Before 2, After 2
   - No new archives: Before 0, After 0
   - Strategy approval preserved: status = approved
   - v2 draft content intact: "最终草稿内容"

**Trigger**:
```sql
CREATE TRIGGER p0310_forced_archive_failure
BEFORE INSERT ON "UserContentArchive"
BEGIN
  SELECT RAISE(ABORT, 'P0.3.10 forced archive failure');
END;
```
