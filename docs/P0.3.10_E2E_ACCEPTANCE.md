## 1. Acceptance Criteria Overview

P0.3.10 PASS requires ALL of the following:

- [ ] Full workflow path is verified (Topic → Research → Knowledge → Angle → Strategy → Approval → Writing → Evaluation → Refine → Humanization → Final → Save → Reload)
- [ ] Strategy Approval Gate is verified (pending/rejected block writing; approved allows writing)
- [ ] Evaluation → Refine is verified (suggestions become issues; selection drives fix)
- [ ] Refine → Humanization is verified (humanization doesn't corrupt source state)
- [ ] Final Output is verified (reflects user's final choice)
- [ ] Draft v1/v2/v3 versioning verified (versions accumulate, old drafts preserved)
- [ ] Old drafts are preserved (no deletion on re-save)
- [ ] Refine metadata persists (changes, linked issues, resolved/unresolved, preserved elements)
- [ ] Humanization metadata persists (adopted flag, result data)
- [ ] Strategy approval persists (approved → save → approved)
- [ ] Transaction behavior verified (rollback on archive failure)
- [ ] Project reload verified (all state recoverable from DB)
- [ ] Error boundaries verified (failures don't corrupt state)
- [ ] Regression tests pass (all existing P0.3.7‑P0.3.9 tests green)
- [ ] Typecheck passes
- [ ] Lint passes
- [ ] Build passes
