## 3. Graph Definition

ContextGraph = ContextNodes + ExplicitEdges

### 3.1 ContextGraphNode

```typescript
interface ContextGraphNode {
  id: string;
  context: ContextObject;
}
```

Graph Node 只是 ContextObject reference。ContextObject 仍然是 source object。Graph 不拥有 ContextObject。

### 3.2 ContextGraphEdge

```typescript
interface ContextGraphEdge {
  id: string;          // deterministic: edge_${type}_${fromId}_${toId}
  fromId: string;
  toId: string;
  type: ContextGraphEdgeType;
  source: 'provenance';
  createdAt: string;
}
```

### 3.3 Edge Types

| Type | Direction | Source Field | Meaning |
|------|-----------|-------------|---------|
| `derived_from` | A → B | `B.provenance.derivedFrom` | B was derived from A |
| `used_by` | A → B | `A.provenance.usedBy` | A was used by B |
| `supersedes` | A → B | `B.provenance.supersedes` | B supersedes A |

### 3.4 ContextGraph

```typescript
interface ContextGraph {
  nodes: readonly ContextGraphNode[];  // sorted by id ASC
  edges: readonly ContextGraphEdge[];  // sorted by type, fromId, toId ASC
  nodeCount: number;
  edgeCount: number;
}
```

## 4. Node Source

ContextObject — Graph 不复制 payload，只引用。

## 5. Edge Source

ContextProvenance — 所有边来自显式 provenance 字段：

- `derivedFrom` → `derived_from` 边
- `usedBy` → `used_by` 边
- `supersedes` → `supersedes` 边

## 6. Scope Isolation

两个 ContextObject 可以产生 Graph Edge 的必要条件：

1. **relationship is explicit** — provenance 中明确声明
2. **scope is compatible** — owner/project/topic 兼容

规则：

| Rule | Policy |
|------|--------|
| owner | 不同 ownerId → 禁止建边 |
| project | 双方都有 projectId → 必须一致 |
| topic | 双方都有 topicId → 必须一致 |
| global | 可与符合规则的 project/topic 关联 |
| unknown | isolated by default |

## 7. Traversal

### 7.1 BFS Algorithm

- 使用 BFS（非 recursive unbounded DFS）
- visited Set 防环
- maxDepth 可控
- deterministic ordering

### 7.2 Defaults

- direction = both
- maxDepth = 2
- MAX_CONTEXT_GRAPH_DEPTH = 10 (clamp)

### 7.3 API

```typescript
getRelatedContexts(graph, nodeId, options?)     // 1-hop
traverseContextGraph(graph, startNodeId, options?)  // BFS N-hop
findContextPaths(graph, fromId, toId, options?)  // shortest path
```

## 8. No LLM

关系不是 AI 猜出来的。所有边来自 explicit provenance。

禁止：
- similar_to
- related_to
- caused_by
- influenced_by
- supports
- contradicts
- about
- depends_on

## 9. No Persistence

Graph 是 derived/on-demand representation。没有 Prisma 模型，没有数据库表。

## 10. No Causal Inference

Graph edge 不代表因果关系。只代表显式声明的来源/使用/替代关系。

## 12. No Mutation of Source

Graph 只能读取 ContextObject。buildContextGraph() 不修改任何输入对象。

验证：
- `context.provenance.derivedFrom` 不变
- `context.provenance.usedBy` 不变
- `context.provenance.supersedes` 不变

## 13. Determinism

相同输入（无论顺序）→ 相同 Graph：

- Nodes: id ASC
- Edges: type ASC, fromId ASC, toId ASC
- Edge ID: `edge_${type}_${fromId}_${toId}`

Edge createdAt 不是 runtime clock。它来自声明该关系的 ContextObject.updatedAt，因此不会因为重新 build graph 而发生变化。

```
derived_from:  B.provenance.derivedFrom = ['A'] → A → B,  createdAt = B.updatedAt
used_by:       A.provenance.usedBy       = ['B'] → A → B,  createdAt = A.updatedAt
supersedes:    B.provenance.supersedes   = 'A'   → A → B,  createdAt = B.updatedAt
```

验证：同一输入重复调用 `buildContextGraph()` 必须产生 `expect(graph1).toEqual(graph2)` — 包括 nodes、edges、edge IDs 和 createdAt。

## 14. Graph → Context Assembly

```typescript
// Traverse graph → ContextObjects → ContextCollection → Assembly
const contexts = getGraphContext(graph, nodeId, { maxDepth: 2 });
const collection = createContextCollection(contexts);
// Feed into existing Context Assembly pipeline
```

## 15. Design Invariants

| Invariant | Enforcement |
|-----------|-------------|
| ContextObject = source node | Graph only references |
| Provenance = relationship evidence | Builder reads fields |
| ContextGraph = derived relationship view | In-memory only |
| ContextGraphQuery = retrieval mechanism | BFS with bounds |
| ContextAssembly = final context packaging | Pipeline unchanged |
