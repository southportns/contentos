# P0.6.1 — Context Object Foundation

## Overview

P0.6.1 establishes a unified **Context Object Layer** that bridges the gap between raw database entities and structured, context-aware data views used throughout ContextOS. This layer provides a clean separation between persistence models and runtime context, enabling entities to evolve independently from how they are consumed.

## Design Principles

| Principle | Description |
|-----------|-------------|
| **Entity ≠ Context** | Database entities store raw data; Context Objects provide structured, computed views |
| **Provenance** | Every Context Object carries metadata about its source and ownership |
| **Lifecycle** | Context Objects track their state from creation through evaluation and learning |
| **Non-breaking** | No schema changes, no existing code modifications |
| **Adapter-based** | Adapters transform entities to Context Objects (external layer) |

## Core Types

### ContextKind

```typescript
type ContextKind =
  | 'identity'    // User, audience, persona
  | 'intent'      // Goals, objectives, direction
  | 'knowledge'   // Facts, context, retrieval results
  | 'strategy'    // Plans, approaches
  | 'content'     // Drafts, media, artifacts
  | 'evaluation'  // Scores, analysis, feedback
  | 'decision'    // Choices, approvals, rejections
  | 'outcome'     // Results, metrics, performance
  | 'memory'      // Historical context, learnings
```

### ContextProvenance

Tracks where a Context Object came from:

```typescript
interface ContextProvenance {
  source?: string | null;       // Entity reference
  sourceType?: string | null;   // 'database' | 'skill' | 'user_input'
  ownerId?: string | null;      // User ID
  projectId?: string | null;    // Project ID
  topicId?: string | null;      // Topic ID
  derivedFrom?: string[];       // IDs of source contexts
  usedBy?: string[];            // IDs of contexts that consumed this
  supersedes?: string | null;  // Previous version
  confidence?: number | null;   // Source confidence
}
```

### ContextLifecycleState

```typescript
type ContextLifecycleStage =
  | 'captured'     // Raw data ingested
  | 'normalized'   // Cleaned and standardized
  | 'stored'       // Persisted to database
  | 'retrieved'    // Loaded for use
  | 'applied'      // Used in a workflow
  | 'evaluated'    // Analyzed/assessed
  | 'updated'      // Modified after use
  | 'learned';     // Feedback incorporated
```
