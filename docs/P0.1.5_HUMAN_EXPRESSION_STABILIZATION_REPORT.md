## 3. Detailed Changes

### 3.1 提升 Personal Specificity（专属经历引导）

**问题**: P0.1.4 报告中 Personal Specificity 距离真人基准差距 -1.0 分（8.3 vs 9.3）。

**解决方案**: 在 `expression-planning/prompts.ts` 中增加"专属经历引导"规则：

```
专属经历引导（P0.1.5 新增）：
- 在 thoughtPath 中，至少 1 个步骤应包含"可泛化但具体"的生活场景
- "可泛化但具体"的含义：场景是大多数人可能经历过的（可泛化），但有独特的感官/情境细节（具体）
- 示例：不是"很多人都有过失败的經歷"（太泛），而是"提交方案那天下午，我盯着邮箱发了十分钟呆"（具体但可共鸣）
- 禁止虚构时间、地点、人物姓名、具体数字（如"三年前"改为"有段时间"）
```

**预期效果**: Personal Specificity 从 8.3 提升至 8.7-9.0 区间。

---

### 3.2 增加结尾多样性（6+ 类结尾模式）

**问题**: P0.1.4 报告中多个案例以"大家有没有发现/有没有想过"结尾，模式单一。

**解决方案**: 从 5 类结尾模式扩展至 8 类：

| # | 模式 | 说明 | 新增 |
|---|------|------|------|
| 1 | `reflection` | 对全文做深度反思或感悟升华 | 已有 |
| 2 | `open_ended` | 留下开放式空间，不做总结 | 已有 |
| 3 | `echo` | 呼应开头的场景或意象 | 已有 |
| 4 | `question` | 提出引人深思的问题 | 已有 |
| 5 | `direct_takeaway` | 直接给出核心观点或结论 | 已有 |
| 6 | **`scene_return`** | 回到一个具体的感官场景或细节 | **新增** |
| 7 | **`self_aware`** | 自我觉察或自嘲，承认表达的局限 | **新增** |
| 8 | **`quiet_statement`** | 轻描淡写的陈述，不过度升华 | **新增** |

**轮换规则**:
- "question" 模式每月使用不超过 40%（避免结尾同质化）
- "scene_return" 和 "quiet_statement" 是高区分度模式，优先推荐

**预期效果**: 结尾多样性显著提升，减少"大家有没有发现"类模板化结尾。

---

### 3.3 降低情绪突转频率（30%-40%）

**问题**: P0.1.4 报告中 6/10 = 60% 案例使用情绪突转，超出推荐范围。

**解决方案**: 在 Expression Planning Prompt 中增加控制规则：

```
情绪突转频率控制（P0.1.5 新增）：
- 情绪突转（emotion_shift）是指在叙事中突然从理性/平静切换到强烈情感
- 推荐使用频率：30%-40%（即 10 个 thoughtPath 步骤中不超过 3-4 个使用情绪突转）
- emotionCurve 中若要设置情绪突转节点，必须在 purpose 中明确标注 [shift]
- 过多情绪突转会导致内容"煽情化"和"模板化"
```

**预期效果**: 情绪突转频次从 60% 降至 30%-40%，减少"煽情化"模式。
